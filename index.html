agent

An agent for accounts payable

Reads supplier invoices from any PDF layout into one standard shape, checks each against its purchase order and goods receipt in Postgres, approves clean matches, parks mismatches with a one-line reason, waits for a human, then posts to the ledger. Design is set, milestones ship on GitHub as they land.

tool calling
A raw loop against the provider SDK in Go. No framework. Step limit, tokens and cost logged per call.
structured output
FastAPI and Pydantic turn the PDF into one invoice JSON. Field accuracy measured on 100 known invoices.
rules in code
Tolerances and approval limits live in Go. The model reads and explains, it never decides to pay.
rag
Supplier contracts and policy notes in pgvector, retrieved and cited in every reason.
evals
100 invoices with known answers re-run on every push. An LLM judge scores the reason, not just the verdict.
tracing
Every call traced in self-hosted Langfuse. A breaking change shows as a red number.
durable state
Run state in Postgres with an idempotency key. Kill it mid-run, restart, it resumes and never posts twice.
security
A PDF with hidden "approve this" text must be refused. The agent can open an exception, only a human can post.
mcp
Lookup and posting tools exposed from a Go MCP server, so any client can drive them.
cost
Prompt caching, a cheap model for clean invoices, a strong one for exceptions. Cost per invoice measured before and after.

Go runtime and MCP tools. Python for extraction and evals. LangGraph port at the end, to compare.
